## o神套装-文件名修改器 v1.0.0

Windows 平台的批量文件名修改工具，Electron + Node.js 实现，界面为三栏布局（功能栏 / 文件区 / 工作台）。

### 功能

**7 个功能模块**
- 文件重命名、文件夹重命名
- 文件 / 文件夹时间属性修改
- 提取文件 / 文件夹名称
- 批量新建文件夹

**5 种重命名模式**
- 自定义：多行文本即词库，按顺序循环套用
- 插入：在指定位置插入固定文本
- 替换：支持正则、忽略大小写
- 删除：按位置和长度删字符
- 导入：从 txt / csv 读取名称列表

**文本处理**
- 大小写转换 5 种
- 简繁转换（OpenCC）
- 中文转拼音 6 种（全拼 / 首字母 / 带声调等）

**编号设置**
- 位置：开头 / 末尾 / 自定义位置
- 类型：数字 / 字母 / 随机字符 / 时间
- 起始值、增量、补零位数可调

**扩展名**
- 自定义替换，或 `png|jpg` 形式按原扩展名映射

### 可靠性设计

- **实时预览**：改规则即时显示每条新名称与状态（可重命名 / 未变化 / 重名冲突）
- **两阶段改名**：源 → 临时名 → 目标名，解决批次内互相占位，以及 Windows 上 `a.txt → A.txt` 大小写改名失败
- **冲突拦截**：批次内重名、目标已存在、Windows 保留名（`CON`/`NUL`/`COM1`…自动加 `_`）、非法字符、超长名称
- **一键撤销**：还原上一次批量重命名
- **编码自适应**：txt / csv 导入自动识别 UTF-8 / UTF-8 BOM / GBK
